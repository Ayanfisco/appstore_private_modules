Easy Configuration

Get started in just 3 simple steps:

1. Go to accounting/sale/website ‣ Configuration ‣ Payment Providers

2. Activate and Configure Paystack

3. Enter your Paystack API Keys

4. Go to accounting/sale/website ‣ Configuration ‣ Payment Methods

5. Activate Paystack Payment Method
