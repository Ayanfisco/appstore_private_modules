Installation & Setup

Quick Installation

  1. Download the module from Odoo App Store
  2. Navigate to Apps menu in Odoo 18
  3. Click "Update Apps List"
  4. Search for "Hotel Management System"
  5. Click "Install"
  6. System installs all dependencies automatically

Initial Configuration

  1. Navigate to Hotel System → Configuration → Properties
  2. Create your first hotel property with all details
  3. Add room types with pricing and capacity
  4. Create amenities and assign to room types
  5. Add all physical rooms to the system
  6. Configure hotel services (restaurant, laundry, etc.)
  7. Set up user access rights (Manager/User)
  8. Configure email templates (optional)
  9. You're ready to start taking reservations!
