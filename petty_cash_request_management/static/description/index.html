How It Works

1

Request Submission

Requesters log into Odoo and submit petty cash requests (≤ ₦10,000) via the Petty Cash Request Module. Fill in amount, division (tied to analytic account), expense budget code, purpose/narration, and upload supporting documents.

2

Automated Approval Workflow

Odoo routes the request to Division Head for initial approval, then to CFO for final approval. Requesters receive notifications of approval/rejection, and approvers are reminded of pending actions.

3

Automatic Posting

Once CFO approval is granted, Odoo automatically posts approved petty cash requests into appropriate accounts. Batches are created by division within the system for seamless processing.

4

Payment Processing

Treasury Officer handles payments below ₦10,000, Payable Officer handles amounts above ₦10,000. Officers review approved batches, process payment using the integrated Bank Payment Module, and Odoo automatically updates division float balances and records transactions in the general ledger.

Installation

  1. Download the module from Odoo App Store
  2. Navigate to Apps menu in Odoo
  3. Click "Update Apps List"
  4. Search for "Petty Cash Management"
  5. Click "Install"
  6. Configure divisions and analytic accounts in Configuration menu
  7. Set up approval workflow (Division Head → CFO)
  8. Assign user access rights (Requester/Division Head/CFO/Treasury Officer/Payable Officer)
  9. Configure Bank Payment Module integration
  10. Start submitting petty cash requests!
