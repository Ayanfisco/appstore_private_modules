📋 Transform Your Requisition Process

Purchase Requisition Flow Management is a comprehensive solution designed to streamline your organization's material and service request process. With an intuitive interface, powerful workflow automation, and seamless integration with Odoo's purchase module, managing requisitions has never been easier.

Built specifically for Odoo 18, this module leverages the latest features and best practices to deliver a robust, scalable, and user-friendly requisition management system that grows with your business.

✨ Powerful Features

🔄

Multi-Level Approval Workflow

Configurable approval stages ensure proper authorization at every level. From department managers to directors, maintain complete control over spending.

🏢

Department-Based Management

Organize requisitions by department with automatic routing to appropriate managers. Perfect for multi-department organizations.

📧

Smart Email Notifications

Automated email alerts keep everyone informed. Approvers receive instant notifications, ensuring quick turnaround times.

🛒

Automatic PO Creation

Convert approved requisitions to purchase orders with one click. Orders are intelligently grouped by vendor for efficiency.

📊

Comprehensive Analytics

Built-in reports, pivot tables, and graphs provide insights into spending patterns, approval times, and requisition volumes.

🔒

Robust Security

Four-tier security model with granular permissions. Users only see what they're authorized to access.

📦

Stock Integration

Check product availability before ordering. See current stock levels directly in requisition lines.

💰

Budget Tracking

Monitor estimated costs in real-time. Set auto-approval thresholds based on requisition amounts.

⚡

Priority Management

Flag urgent requisitions to expedite processing. Three priority levels ensure critical needs are met quickly.

📱

Mobile Responsive

Manage requisitions on-the-go. Optimized Kanban view works perfectly on mobile devices.

🌐

Multi-Company Support

Perfect for organizations with multiple entities. Company-specific requisitions with proper data isolation.

📝

Complete Audit Trail

Track every action with integrated chatter. Know who did what and when for complete accountability.

🔐 Security Groups

Four-Tier Access Control

👤 Requisition User

Permissions:

  • Create requisitions
  • View own requisitions
  • View department requisitions
  • Submit for approval

👔 Requisition Manager

Permissions:

  • All User permissions
  • Approve department level
  • View all requisitions
  • Access approval queue

🎓 Requisition Director

Permissions:

  • All Manager permissions
  • Give final approval
  • Override approvals
  • Full visibility

⚙️ Requisition Administrator

Permissions:

  • All Director permissions
  • Configure settings
  • Delete requisitions
  • Full system access
