How It Works

1

Setup & Configuration

Create vehicle brands (Toyota, Honda, Ford), models (Camry 2024, Accord 2024), and configure user permissions for Salespeople and Managers.
2

Vehicle Acquisition

Create purchase orders with supplier details, vehicle information (VIN, brand, model, year, color), and complete cost breakdown. Track status from Draft → Ordered → In Transit → Received. System automatically creates vehicle records in inventory upon receipt.
3

Inventory Management

Set selling prices, upload vehicle photos, add features and specifications, and manage vehicle notes. Optional pre-sale inspections can be conducted before listing.
4

Sales Process

Create sale orders with customer selection, vehicle selection (auto-reserves vehicle), pricing with discounts, trade-in handling, and flexible payment methods. Support for cash, financing (with loan calculator), bank transfer, and check payments. Generate invoices, collect signed documents, and mark as delivered.
5

Service & Maintenance

Schedule service appointments (vehicle status changes to "In Service"), assign technicians and workshops, track parts replaced and labor costs, handle warranty coverage, and set next service reminders. Complete service history is maintained for each vehicle.
6

Inspections & Reports

Conduct comprehensive vehicle inspections with ratings for exterior, interior, engine, transmission, tires, and brakes. Document issues found, provide recommendations with cost estimates, upload photos, and generate professional PDF inspection reports for customers.

Detailed Workflow Examples

Purchase Workflow Example

Scenario: Purchasing a Toyota Camry 2024 from ABC Auto Imports

  1. Create Purchase Order: Navigate to Purchases → Purchase Orders → Create. Enter supplier (ABC Auto Imports), vehicle details (Brand: Toyota, Model: Camry 2024, VIN: 1HGBH41JXMN109186, Color: Silver, Mileage: 0 km), and costs (Purchase Price: $25,000, Shipping: $800, Import Duty: $1,200, Other: $300). Total Cost: $27,300. Save as Draft.
  2. Confirm Order: Click "Confirm Order" button → Status changes to "Ordered". Set expected arrival date (e.g., 2026-01-30).
  3. Mark In Transit: When vehicle ships, click "Mark In Transit" → Status changes to "In Transit".
  4. Receive Vehicle: Upon arrival, click "Receive Vehicle" → Status changes to "Received". System automatically creates Vehicle Record (Reference: VEH00001) with all details, purchase price ($27,300), status: AVAILABLE, and links to purchase order.

Service Workflow Example

Scenario: Routine maintenance for Camry 2024 (VEH00001)

  1. Schedule Service: Navigate to Service → Service Records → Create. Select Vehicle (VEH00001 - Camry 2024), vehicle status automatically changes to "IN SERVICE". Enter service date (2026-02-15), service type (Routine Maintenance), assign technician (Tom Wilson), select workshop (Main Service Center), enter current mileage (5,000 km). Add description: Oil change, Tire rotation, Multi-point inspection. Save → Status: SCHEDULED.
  2. Start Service: Click "Start Service" button → Status changes to "IN PROGRESS". Vehicle marked as unavailable for sale.
  3. Complete Service: Enter parts replaced (Oil filter, Engine oil 5L), labor cost ($80), parts cost ($45), total cost ($125). Indicate warranty coverage (No), set next service date (2026-08-15). Click "Complete" → Status: COMPLETED.
  4. Result: Vehicle status returns to "AVAILABLE", mileage updated to 5,000 km, service history recorded, reminder set for next service.

Inspection Workflow Example

Scenario: Pre-sale inspection for Camry 2024

  1. Create Inspection: Navigate to Service → Inspections → Create. Select Vehicle (VEH00001 - Camry 2024), inspection date (2026-01-17), assign inspector (Sarah Martinez), select type (Pre-Sale Inspection).
  2. Rate Components: Rate each component: Exterior Condition (Excellent), Interior Condition (Excellent), Engine Condition (Excellent), Transmission Condition (Good), Tire Condition (Excellent), Brake Condition (Good). Overall Rating: 9/10. Mark as Passed: Yes.
  3. Document Issues: List issues found: Minor scratch on rear bumper, Brake pads at 40% (normal). Provide recommendations: Touch up paint on scratch, Monitor brake pads. Estimated repair cost: $150.
  4. Generate Report: Upload 8 inspection photos. Click "Generate PDF Report" to create professional inspection report that can be emailed to customers.

Installation

  1. Download the module from Odoo App Store
  2. Navigate to Apps menu in Odoo
  3. Click "Update Apps List"
  4. Search for "Vehicle Dealership Management"
  5. Click "Install"
  6. Configure vehicle brands and models in Configuration menu
  7. Set up users and assign access rights (Salesperson/Manager roles)
  8. Create suppliers in Purchase module
  9. Start creating purchase orders and managing your dealership!
